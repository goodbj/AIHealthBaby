## 交付内容

### 后端（backend/）

| 文件 | 内容 |
|------|------|
| `app/ocr.py`（新增） | OCR 引擎抽象层：RapidOCR 实现（PaddleOCR PP-OCRv4 模型 ONNX Runtime 本地推理，免装 paddlepaddle），惰性单例 + 双检锁，`BaseOCR` 抽象可切云 OCR |
| `app/routes/records.py`（新增） | 病历闭环路由：`POST /api/records/upload`（multipart ≤5 图→OCR→LLM→落库）、`GET /list`（时间轴倒序）、`GET /{id}`、`POST /{id}/confirm`（确认修正→confirmed）、`DELETE /{id}`、`GET /image/{filename}`（原图，防目录穿越） |
| `app/routes/auth.py`（新增） | 演示一键登录（固定验证码 `YKB_DEMO_SMS_CODE`，默认 123456）+ `/api/user/profile`，JWT 复用 admin 基建，支撑 Android 全 app 联调 |
| `app/llm.py`（改造） | `extract_medical_info` 从空桩升级：在线调 DeepSeek（JSON mode，temperature 0.1）提取诊断/指标/用药/置信度；异常或无密钥回落离线正则桩（诊断行/指标行/用药行提取），链路永不断 |
| `app/routes/__init__.py` | 挂载 records（`/api/records`）+ auth 路由 |
| `requirements.txt` | +`rapidocr-onnxruntime`、`pillow` |
| `tests/test_m1_records.py`（新增） | 11 用例：上传端到端/用户校验/非法扩展名/白图拒绝/时间轴排序/确认修正/404/删除清图/admin 联动/离线提取规则/auth 登录+profile |
| `tests/test_llm_and_hooks.py` | 离线桩 confidence 断言 0.0→0.2（桩升级对齐） |

## 验收证据（可复跑）

1. **单元/集成测试**：`cd backend && python -m pytest -q` → **59 用例全绿**（M0 17 + M2 + M3 15 + M1 11 + 其余）。
2. **真实 OCR 引擎验证**：RapidOCR 识别中文化验单样张准确（诊断/指标/姓名科室逐行还原），模型加载 ~2s、推理 ~1.2s。
3. **端到端实测**（uvicorn 真服务 + RapidOCR 真引擎 + 离线桩结构化，2026-11-10）：
   - `POST /api/records/upload` multipart 上传化验单 PNG → **全链路 2.64s**（≤5s 达标）
   - 返回 `status=pending, confidence=0.5, diagnosis=高血压2级, indicators=[血压 145/95 偏高, 空腹血糖 7.8 偏高]`，OCR 全文落库
   - `POST /{id}/confirm` 修正诊断 → `status=confirmed`；`GET /list` 时间轴可见；`GET /image/{f}` 原图 26KB PNG 回读正常
4. **APK 打包**：`gradle assembleDebug`（15.5M）+ `assembleRelease`（10.5M unsigned）均 BUILD SUCCESSFUL（本地 tools/jdk+sdk）。

## 复跑指引

```bash
cd backend
pip install -r requirements.txt
export YKB_DATABASE_URL="sqlite+aiosqlite:///./yikangbao.db"
uvicorn app.main:app --port 8000
# 上传：POST /api/records/upload (multipart: user_id + images)
# 登录：POST /api/auth/login {"phone":"138xxxxxxxx","code":"123456"}

cd android
# 用 android/tools 下的 jdk/gradle/sdk：
# JAVA_HOME=<repo>/android/tools/jdk ANDROID_HOME=<repo>/android/tools/android-sdk
# gradle assembleDebug → app/build/outputs/apk/debug/app-debug.apk
```
